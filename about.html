About CyberSafe

CyberSafe is a cybersecurity awareness website created to help users understand common cyber threats and learn basic methods of protecting themselves online.

The website provides simple explanations of cybersecurity topics along with interactive features that allow users to test their knowledge.

Project Purpose

The purpose of this project is to create an educational platform that makes basic cybersecurity concepts easier to understand.

It also demonstrates how web development and programming can be used to create useful cybersecurity-related tools.

Project Features

  • Cybersecurity awareness information
  • Common cyber threat explanations
  • Cyber safety tips
  • Password strength checker
  • Interactive phishing awareness quiz
  • Quiz scoring system
  • Responsive website design

Technologies Used

  • HTML - Website structure
  • CSS - Website design and layout
  • JavaScript - Interactive features

What I Learned

Through this project, I practiced HTML structure, CSS styling, JavaScript programming, user interaction, basic cybersecurity concepts and website organization.
