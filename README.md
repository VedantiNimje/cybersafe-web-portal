# Cyber Security Awareness Website

A beginner-friendly cybersecurity awareness website created as a student project. The website provides information about common cyber threats, cyber safety tips, password strength checking, and a phishing awareness quiz.

## 📌 Project Description

This project is designed to help users understand basic cybersecurity concepts and develop safer online habits.

It includes interactive features such as a password strength checker and a phishing awareness quiz.

## ✨ Features

- 🏠 Home page
- ⚠️ Common Cyber Threats
- 🛡️ Cyber Safety Tips
- 🔐 Password Strength Checker
- 🎣 Phishing Awareness Quiz
- ℹ️ About page
- 📱 Simple and user-friendly navigation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
