# 🛡️ CyberSafe – Cybersecurity Awareness Website

CyberSafe is a cybersecurity awareness website designed to help users learn about common cyber threats and practice safe online habits.

The website provides simple cybersecurity information, safety tips, a password strength checker, and an interactive phishing awareness quiz. It also includes user registration, login, profile, and dashboard functionality using PHP.

## 🌐 Project Features

### 🏠 Home
- Introduction to CyberSafe
- Simple and user-friendly interface
- Navigation to different cybersecurity sections

### ⚠️ Cyber Threats
Provides information about common cybersecurity threats such as:
- Malware
- Phishing
- Denial-of-Service (DoS/DDoS)
- Other common online threats

### 🔐 Safety Tips
Provides basic cybersecurity practices, including:
- Creating strong passwords
- Protecting personal information
- Avoiding suspicious links
- Following safe browsing practices

### 🔑 Password Checker
- Checks password strength
- Categorizes passwords as Weak, Medium, or Strong
- Helps users understand the importance of stronger passwords

### 🎯 Phishing Quiz
- Interactive phishing-awareness quiz
- Multiple questions
- Displays the user's score
- Helps users identify suspicious online messages and links

### 👤 User Authentication
The website also contains PHP-based user functionality:
- Sign Up
- Login
- Dashboard
- Profile
- Edit Profile
- Logout

## 🛠️ Technologies Used

- **HTML** – Website structure
- **CSS** – Website styling and layout
- **JavaScript** – Interactive features such as the password checker and phishing quiz
- **PHP** – User authentication and profile functionality
